# Contributing

Thanks for contributing to pocket-ledger.

## Workflow
- Create a branch from `main`
- Open a Pull Request
- Keep PRs small and focused
- Use conventional commits

## Commit style
- `feat:` new features
- `fix:` bug fixes
- `chore:` maintenance
- `docs:` documentation
- `refactor:` code changes without behavior change
- `test:` tests

## Quality gates
- CI must pass before merge
- No direct pushes to `main`
